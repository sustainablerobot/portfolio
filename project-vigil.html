VIGIL

Industrial safety monitoring that scores how dangerous a combination of signals is.

My part

End to end: system architecture, the nine-module design, the 11-rule risk engine and scoring, incident memory, and the vision module.

Inside
  • Nine modules working together
  • 11 rules combine into a 0–100 risk score
  • Past incidents retrieved with FAISS and the Claude API
  • OpenCV vision; optional YOLOv8 for worker and protective-gear detection on edge hardware
Context

Built for ET AI Hackathon 2.0.

Stack

Python · OpenCV · YOLOv8 · FAISS · Claude API · Streamlit
